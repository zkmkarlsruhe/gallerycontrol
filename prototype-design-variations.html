⚡ Why Separate Subnets?
  • Security: Power control devices isolated from application network
  • UDP Broadcasts: ANEL devices push status updates - broadcasts stay in control network
  • Real-time: Sub-second latency from device action to UI update (no polling!)
  • Network Isolation: Only ANEL runner has access to control devices
